# About `ambient-loop.mp3`

`ambient-loop.mp3` is an ethereal, choir-and-pad ambient loop (2 min 38 s) made
for the music example. It was generated by Sacha with ElevenLabs Music and then
trimmed and crossfaded into a seamless loop with `tools/make-loop.py`.

**The track is not covered by the MIT license that applies to the code in this
repository.** It is included only so the music example and the playground work
out of the box. If you want to reuse the track in your own project, check that
the ElevenLabs terms that apply to it allow your use, or replace it with music
you have the rights to.

To use your own music, point the `audio` attribute at any MP3, M4A or OGG file
on your site:

```html
<caustic-light preset="silk" audio="/music/your-track.mp3" audio-controls></caustic-light>
```
